# 在 Edge 浏览器里安装「招聘捕手」扩展

Edge 是 Chromium 内核，和 Chrome 用**同一套 MV3 扩展格式**，所以 `招聘agent-build/extension/`
这一份产物**两边通用**，不需要为 Edge 单独打包。

---

## 一、先确认产物是新的

装之前跑一次自检，避免拿到半成品：

```bash
cd <项目所在目录>/招聘agent
npm run icons        # 首次需要（生成图标）；已生成可跳过
npm run build        # 构建三端
npm run verify:ext   # 自检扩展产物完整性
```

`verify:ext` 会检查 manifest 引用的每个文件是否存在、权限是否齐全、
popup 是否挂上。看到 **「全部引用文件存在，可直接加载到 Edge」** 就没问题。

产物目录长这样（**注意要选的是 `extension` 这一层**）：

```
<项目所在目录>/招聘agent-build\extension\
├── manifest.json      ← Edge 靠这个识别扩展
├── background.js      ← 后台逻辑（队列 + 同步）
├── content.js         ← 注入到招聘网站页面
├── popup.html         ← 点图标弹出的面板
├── popup.js
└── icons\             ← 16 / 32 / 48 / 128 图标
```

## 二、安装步骤（4 步）

### 1. 打开扩展管理页

地址栏直接输入：

```
edge://extensions
```

或：右上角 `…` → **扩展** → **管理扩展**。

### 2. 打开「开发人员模式」

页面**左下角**（Edge 新版在**左侧栏底部**）把 **开发人员模式** 开关打开。

打开后会多出一排按钮：`加载解压缩的扩展`、`打包扩展`、`更新`。

### 3. 加载扩展

点 **`加载解压缩的扩展`**（Load unpacked），在弹出的文件夹选择框里定位到：

```
<项目所在目录>/招聘agent-build\extension
```

> ⚠️ **选目录，不要选里面的文件**。选中 `extension` 这一层，确保它直接包含 `manifest.json`。
> 选错层次会报「清单文件缺失或不可读」。

选好后扩展就出现在列表里了，名字是 **招聘捕手 · Resume Catcher**。

### 4. 固定到工具栏

默认它藏在「扩展」拼图图标里。点地址栏右侧的 **拼图图标** → 找到「招聘捕手」→
点旁边的 **眼睛/图钉图标** 固定，图标（靛蓝放大镜）就会常驻工具栏。

---

## 三、验证装好了

**点一下工具栏上的图标**，应该弹出这个面板：

| 显示项 | 正常状态 |
|---|---|
| 顶部圆点 | 🟢 绿点 + `后端已连接 · http://localhost:8787` |
| 本地待上传队列 | `0` 份简历（绿色） |
| 已入库 / 判重跳过 / 最近同步 | 有数字和时间 |
| 当前标签页 | 显示你正在哪个站、是不是简历页 |

**后端圆点是红的**说明看台服务没起来——扩展照常采集，数据会先存在本地队列里，
等服务起来会自动补传（这就是「断网不丢」设计）。启动服务：

```bash
cd <项目所在目录>/招聘agent
npm run start
```

再去 `edge://extensions` 点一次扩展卡片上的**刷新按钮**，或在 popup 里点「立即同步」。

## 四、实际采集流程

0.4.0 起扩展有**三档采集模式**，默认是「保存前询问」：

| 模式 | 行为 | 适合 |
|---|---|---|
| **保存前询问**（默认） | 识别到简历 → 页面右下角弹卡片问「保存到看板 / 这次不存 / 本页都不再问」，**不点不存** | 想把关每一份 |
| **自动** | 识别到就静默入库，页面上只留一个收起的小圆点（点开可手动补采） | 回到「无感」 |
| **关闭** | 完全不采集，页面零打扰。仍可在 popup 里手动保存当前页 | 暂时不想采 |

模式在**点扩展图标后的面板顶部**切换，**改完立即生效，不用刷新页面**。

以默认的「保存前询问」为例：

1. **在 Edge 里登录** BOSS直聘 / 猎聘（用你自己平时用的账号，正常登录即可）
2. 打开任意一份**简历详情页**
3. 页面加载约 1.2 秒后，右下角出现卡片：「识别到 **张小雨** · 1,842 字 · 尚未入库」
4. 点 **「保存到看板」** → 卡片给出回执（「已手动保存到看板 ✓」）
   - 若看台服务没起，回执会如实说「后端没连上，已排进本地队列」——服务起来后自动补传，**不会丢**
5. 点 **「这次不存」** 就跳过这一份；点 **「本页都不再问」** 则整页静默（7 天后自动失效，或在 popup 里恢复）

打开 `http://localhost:8787/` 的**候选人库**，刚存的人就在列表里了。
在候选人详情的「来源与留痕」里能看到这份是**自动采集**还是**手动保存**的。

### 页面右下角那个小圆点

- **auto 模式**：收起成小圆点（点一下展开），里面有「再存一次」/「这次不存」
- **confirm 模式**：识别到简历时自动展开成询问卡；没识别到时收起
- 可以**拖动**到不碍事的位置，位置会记住（默认避开右下角，那里常有站点自己的客服按钮）
- 它用 Shadow DOM 隔离，不会和猎聘/BOSS 的页面样式互相污染

### 「自动没抓到，但我知道这是简历」怎么办

点卡片上的「保存到看板」，或用 popup 里的同名按钮 —— 这会走**放宽门槛**的提取，
把界面上最像简历的那一块救回来。如果正文可能不完整（偏短 / 没拿到平台 ID / 只能
退化成整页文本），回执会**明确告诉你**，需要你判断要不要留：

> 「已保存，但请注意：未识别到平台 ID，已按内容指纹建档，可能与历史记录重复。」

### 列表页会主动让路

像 `lpt.liepin.com/recommend`（人才推荐）这种**一屏多人**的页面，聚合文本很容易被
误判成「一份简历」，存进去就是一条包含多个人的脏数据。所以：

- 命中列表页规则时**不自动采集**，卡片会说明「这一页像是列表页，已跳过自动采集」
- 想存某个人的简历：**点开他的在线简历**，再点「保存到看板」

**只读原则**：扩展只抓取**你当前页面上肉眼已可见**的文字，不额外发起请求、
不绕过登录风控、不批量翻页、不支持多账号。你看到什么，它才记什么。

## 五、改了代码之后怎么更新

扩展**不会自动同步源码变更**，必须重新构建后在 Edge 里刷新：

```bash
npm run build          # 重新生成产物
```

然后到 `edge://extensions` → 找到「招聘捕手」→ 点卡片上的 **🔄 刷新** 按钮。

> 如果改了 `content.js` 却没生效，还要**刷新那个招聘网站的标签页**——
> content script 是页面加载时注入的，不刷新页面还是旧代码。

### ⚠️ 别用「打包扩展」装 crx

Edge 扩展页右上角有个「打包扩展」按钮。它生成的 `.crx` 是**一次性快照**：

- 你后来 `npm run build` 了，crx 不会跟着变
- 在扩展页点「刷新」也没用（crx 装的是副本，不指向目录）
- 结果就是你一直在跑旧代码，却以为改动没生效

**用「加载解压缩的扩展」就好**——它直接指向目录，构建完点一下刷新立即生效。

> `招聘agent-build/extension.pem` 是打包用的私钥，**不要提交到 git、不要外传**。
> 它位于仓库同级目录，git 不会跟踪。

## 六、常见问题

### 加载时提示「清单文件缺失或不可读」
选错目录了。你要选的是**包含 `manifest.json` 的那个目录**：
`招聘agent-build\extension`，不是它的上级 `招聘agent-build`，也不是里面的 `src`。

### 工具栏看不到图标
没固定。点地址栏右侧的拼图图标，在列表里找「招聘捕手」，点图钉固定。

### 点图标没反应 / 面板空白
1. 先确认产物里有 `popup.html`（`npm run verify:ext` 会告诉你）
2. 到 `edge://extensions` 点扩展卡片上的**刷新**
3. 还不行就点卡片上的 **「错误」/「Errors」** 按钮看具体报错

### Edge 启动时提示「请停用开发人员模式扩展」
正常现象。未上架商店的扩展都会提示。建议：
`edge://extensions` → 左下角 **「开发人员模式扩展」相关提示** 里选择不再提示，
或直接把 Edge 启动时的这个横幅关掉。

> 装到 `.chrome-debug-profile` 那套调试配置里的是**另一个独立 Edge/Chrome 实例**，
> 和这里手动装的是两回事，各自独立。

### 简历页打开了但没采集

**先看专门文档：[docs/采集排查指南.md](./采集排查指南.md)** —— 五步定位法 + 页面内置的
`__ria.scan()` 诊断 + 结论对照表。

最快的自查路径：

1. **点扩展图标 → 「诊断当前页」**，面板会直接告诉你有没有识别到简历内容
2. 或在页面上按 F12，Console 里执行 `__ria.scan()`

> **猎聘用户注意**：HR 用的猎聘企业端在 **`lpt.liepin.com`**（不是 `www.liepin.com`）。
> 0.1.0 版本的扩展只匹配了主站，在企业端页面上**完全不会注入**。
> 请确认 `edge://extensions` 里的版本号 ≥ **0.2.0**。

其他常见原因：

- **没登录**——未登录时页面没有简历内容可抓
- **没点开简历**——停留在会话列表 / 搜索结果页不采集，要打开某一份在线简历
- **简历是图片 / canvas 渲染**——DOM 里没有文字，`innerText` 拿不到。
  在简历上按 `Ctrl+A` 试试：选不中文字就属于这种，需要 P2 的「截图 + 多模态解析」方案

### 后端地址不对（要连别人的服务器）
扩展的后端地址是**构建期写死**的。改 `.env` 里的 `VITE_API_BASE`：

```
VITE_API_BASE=http://192.168.1.100:8787
```

然后 `npm run build` 重新构建，再到 Edge 刷新扩展。
同时记得把该域名加进 `apps/extension/manifest.json` 的 `host_permissions`，
否则浏览器会拦截跨域请求。

### 想卸载 / 重装
`edge://extensions` → 卡片右下角 **「删除」**。
重装就是重新「加载解压缩的扩展」，**登录态和本地队列会一起清掉**
（数据存在扩展自己的 storage 里，删扩展即清空）。

### 能同时装到 Chrome 吗
可以，加载同一个 `extension` 目录即可。但**两边是独立的存储和独立的登录态**，
各自采各自的，看台会把两边上报的合并去重。

## 七、这个扩展做了什么（权限说明）

| 权限 | 用途 |
|---|---|
| `storage` | 本地缓冲采集队列，断网/关页面不丢数据 |
| `activeTab` | popup 里判断当前标签页是不是简历页 |
| `alarms` | 每 5 分钟兜底重试一次同步 |
| `host_permissions: zhipin.com / liepin.com` | 在这两个站点注入采集脚本 |
| `host_permissions: localhost:8787` | 把采集到的简历 POST 到你的看台后端 |

扩展**不会**读取其他任何网站，也**不会**把数据发往除你自己后端以外的地址。
